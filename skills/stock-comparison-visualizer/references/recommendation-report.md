# 股票推荐报告契约

## 三种结果状态

- `RULE_SNAPSHOT`：尚无活动预测模型或可引用的已评测策略模板，但缓存日线足以完成即时因子排序。按用户本金和最多持仓数排除已触发减仓/卖出风险的股票，再按因子、预测方向和波动形成研究权重，以 A 股整手取整，返回每只建议股票的研究金额、股数和剩余现金。首屏主图以本金为起点，将各股票同分位价格路径和零收益现金汇总为组合 P10/P50/P90 未来金额走线；该汇总不是相关性模拟。每只建议股票默认收在折叠项，用最近 90 根日 K、预测中位线和 P10-P90 扇形区间绘图。样本足够时，1/5/15/30/60/120 分钟和日/周/月/季/年的 P10/P25/P50/P75/P90 价格范围、历史上涨参考、样本数和实际来源统一收在“专业数据与计算依据”。研究分配和组合走线尚未经过本组合样本外校准，不得写入 `positions`，不得冒充真实持仓、成交、账户盈亏、活动模型概率或收益承诺。只有减仓/卖出风险条件实际触发时才显示复核结论；成本止损、账户盈亏和卖出数量在没有真实持仓时保持不可用。
- `CUSTOM_SNAPSHOT`：页面保存的关注重点已经参与最近交易日的候选打分和排序，但当前股票池尚未按该参数版本跑完盘后回测。收益曲线和回撤如引用相近正式模板，必须紧邻标注，不能说成当前股票池成绩。
- `ACTIVE`：同一参数版本已完成半年递推样本外验证、最终留出、风险和非退化门禁。失败或中断保留上一 `ACTIVE`，不得用新候选覆盖。

## 准确度与历史表现

报告同时给出以下内容，指标不可用时写明原因：

1. 一交易日方向准确率、AUC、Brier 分数、概率校准分箱、样本数和 95% Wilson 区间。
2. 每日按当时可得概率选前 K 只，分别计算 1、5、20 个交易日后上涨的命中率、样本数和 95% 区间。5/20 日命中率不是 5/20 日概率校准值。
3. 留出集总收益、年化收益、相对基准超额收益、最大回撤、年化波动、Sharpe、Calmar、胜率、盈亏比、换手、模拟交易成本、最差月份、滚动验证稳定性和最差窗口。
4. P10/P50/P90、达到用户目标的历史比例和亏损比例必须说明采用未参与调参的留出净收益进行连续 5 日区块抽样，不构成未来承诺。

## 数据审计

- 默认滚动队列为最近 3 年约 756 个共同交易日；可选 1/3/5 年。每天盘后加入最新开市日，并移除窗口外最旧数据。
- 以 126 个交易日为一个半年期逐步向前。第一期使用冻结基线；以后每期只能用已结束时期选择参数，本期成绩只允许影响下一期。逐期列出形成截止日、检验区间、参数版本、是否换参、样本外收益和最大回撤；最后一期标为选参后只打开一次的独立检查。
- 列出所有股票、纳入/剔除状态、原因、最早/最晚数据日和交易日数量。
- 行情来自通达信前复权日线；历史财务只使用 `NOTICE_DATE <= signal_date`，估值只使用 `valuation_asof <= signal_date`。公开公告、研报、新闻和情绪必须带来源与日期。
- 成交模拟必须披露佣金、最低佣金、印花税、滑点、整手、成交量参与率、停牌、涨跌停近似和 T+1。

## 股票画像

每只候选按通俗名称展示：公司赚不赚钱和增长快不快、现金够不够和负债重不重、价格贵不贵、近期走势、价格稳定性、成交活跃度、股东变化、管理层变化、重大公告、行业位置、新闻研报情绪和风险事件。每类包含 `status`、`source`、`asof`、实际指标与缺失原因；不允许把缺失值当作零分。

## 页面语言

- 页面只有一套默认视图，核心结论优先展示；专业字段放在可展开区域，不再用字号差异制造“通俗/专业”两套模式。
- “最多尝试方案数”显示为“每个风险档位最多比较多少套参数”，并说明越大只代表盘后比较更多方案、耗时更长，不保证收益更高。
- 表格顺序固定为正式推荐、重点关注、条件通过未入选、暂不推荐；不得为了“看起来有收益”放宽正式风险门禁。
