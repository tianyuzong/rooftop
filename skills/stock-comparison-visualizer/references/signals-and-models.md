# 信号与模型契约

## 模型

- 模型定义不可变，以 `model_key + version` 唯一标识。
- `financial` 与 `valuation` 模型必须使用 `dimensions`，每个指标只引用允许的财务/估值字段，并提供 `low < high`。
- 作用域为 `DEFAULT / INDUSTRY / SYMBOL`，优先级依次提高；可选风险档位为 `aggressive / balanced / conservative`。
- 创建模型需要维护人；激活模型需要批准人和明确确认。新激活只归档相同类型、作用域、范围和档位的旧分配。
- 运行时强制 `research_only=true`、`order_execution=false`，并拒绝代码执行、进程、密钥和券商相关字段。
- MVP 运行时消费财务和估值模型。因子、策略、风控类型目前只有版本化声明存储，不得声称已影响正式信号。

## 信号

- 正式组合新增股票为 `BUY`，移除为 `SELL`，数量或权重变化为 `REBALANCE`，无实质变化为 `HOLD`。
- 非正式版本和未过门禁候选为 `WATCH`。
- 信号必须保留数据截止日、组合版本、验证状态、参考价/数量、止盈止损参考、原因、证据摘要和失效条件。
- 状态只有待复核、已确认、已忽略和已被新版本替代；没有成交状态。

## 通知

- 订阅按事件类型与最低置信度过滤，可限制到单一量化授权书。
- outbox 使用信号与订阅组成的去重键，失败最多退避重试 5 次。
- 通知失败不回滚已经发布的研究版本；信号页面必须显示未发送或重试状态。
- SMTP 凭证只从环境变量读取，不进入数据库、日志或 API 返回。
