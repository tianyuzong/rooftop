# 图表 UI 像素区域与交互契约

本文是价格图的布局验收基准。修改 `app/static/app.js` 或 `app/static/styles.css` 时，必须同步更新本文，并重新执行浏览器拖动、悬浮、颜色切换及截图测试。

## 坐标基准

以 `#chart` 左上角为坐标原点。图表实际宽度记为 `W`，最小为 760 px。右侧筹码面板固定宽 225 px，两列间隔固定为 8 px；左侧主图及三个指标子图的共同宽度记为 `M = W - 233`。

### 横向区域

| 功能区域 | 通用像素范围 | `W = 1000 px` 时 |
|---|---:|---:|
| 左侧主图/指标列 | `x = 0–M` | `0–767` |
| 主图区左侧纵轴刻度 | `x = 0–58` | `0–58` |
| K线/分时/纪律线有效绘图区 | `x = 58–(M-8)` | `58–759` |
| 主图区右内边距 | `x = (M-8)–M` | `759–767` |
| 两列间隔 | `x = M–(M+8)` | `767–775` |
| 筹码分布完整面板 | `x = (W-225)–W` | `775–1000` |
| 筹码柱实际绘制区 | `x = (W-217)–(W-50)` | `783–950` |
| 筹码纵轴线 | `x = W-46` | `954` |
| 筹码纵轴刻度文字区 | `x = (W-41)–(W-6)` | `959–994` |

SVG 的 `viewBox` 宽度必须取左侧列的实际像素宽度 `M`，不得把固定宽度 SVG 非等比压入动态宽度容器。价格纵轴数字固定在主绘图区左侧。

### 纵向区域

| 功能区域 | 像素范围 |
|---|---:|
| 悬浮行情栏 | `y = 0–42` |
| 行情栏与图体间隔 | `y = 42–46` |
| 左侧主图 | `y = 46–386` |
| 主图有效价格区 | `y = 54–358`（主图 SVG 内 `8–312`） |
| 主图与成交额间隔 | `y = 386–391` |
| 成交额子图 | `y = 391–473` |
| 子图间隔 | `y = 473–477` |
| KDJ 子图 | `y = 477–559` |
| 子图间隔 | `y = 559–563` |
| MACD 子图 | `y = 563–645` |
| 筹码柱区域 | `y = 46–573` |
| 筹码 70%/90% 信息区 | `y = 573–645` |

筹码完整面板与左侧图体都固定高 599 px（`y = 46–645`）。因此筹码面板下沿必须与 MACD 子图下沿处于同一条水平线，浏览器实测误差不得超过 1 CSS px。筹码柱与底部 70%/90% 信息区不得重叠。筹码价格轴固定划分为 120 个分箱；在 511 px 的有效柱体高度中，单柱厚度约为 3.66 px，约等于旧版 30 分箱、14.65 px 柱体的 1/4。筹码面板右侧保留 46 px 纵轴区，绘制 8 个由高到低的价格刻度；刻度与筹码柱使用同一组 `min/max` 和纵向映射。

## 鼠标交互区域

- 左键拖动和滚轮缩放由左侧主图表面接收：`x = 0–M, y = 46–386`。按下后由 `document` 持续接管 `pointermove`，图表重绘不得中断拖动。
- K线/分时悬浮的有效价格横轴为 `x = 58–(M-8)`；行情数据写入 `y = 0–42`。
- 十字线纵线同步覆盖左侧价格图、成交额、KDJ 和 MACD；横线仅覆盖价格有效绘图区。
- 筹码面板不是平移或缩放的命中区域，避免误操作。

## 刻度、字体与颜色约束

- 主图纵轴固定绘制 8 个刻度（旧版 5 个的 1.6 倍），刻度数字位于左侧 `x = 4`，网格线从 `x = 58` 开始。
- 图内普通文字使用纯白 `#FFFFFF`、不透明度 `1`、加粗；不得使用灰色或半透明文字。
- 背景必须沿用页面深蓝设计语言：图面 `#08151E`、信息区 `#0C1822`、普通分隔线 `#1E3342`、强调分隔线 `#294653`。禁止出现纯黑大色块或完整白色外框。
- “涨跌颜色”为“红涨绿跌”时，正涨跌幅为 `#FF5E6C`，负涨跌幅为 `#31D6A0`；选择“绿涨红跌”时两者对调。标的涨跌幅、悬浮栏“涨跌幅”和“至今涨幅”必须同步切换。
- K线、指标线和筹码柱可以使用涨跌色；纪律线沿用各自语义颜色。

## 浏览器验收

1. 筹码面板下沿与 MACD 子图下沿之差不超过 1 px。
2. 主图存在 8 个纵轴刻度，全部位于绘图区左侧。
3. 切换两种“涨跌颜色”后，标的涨跌幅和悬浮行情栏涨跌幅同步换色。
4. 左键向右持续拖动时，可见窗口起点减小，拖动期间图表持续更新。
5. 悬浮不同 K 线时，日期、OHLC、换手、量、额和至今涨幅发生变化，十字线可见。
6. 页面从上到下存在成交额、KDJ、MACD 三个子图；筹码柱和底部信息互不覆盖。
7. 筹码 SVG 包含 120 根价格分箱柱；单柱高度约为 3.66 px，柱间留有可见间隔。
8. 筹码面板右侧存在 8 个价格纵轴刻度，最高价在上、最低价在下，文字不越过面板右边缘。
9. 浏览器控制台无 JavaScript 错误，图表没有纯黑背景块和完整白色边框。
