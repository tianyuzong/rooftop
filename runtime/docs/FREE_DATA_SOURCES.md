# 免费数据源实施清单

## 行情与 ETF

| 优先级 | 公司/产品/服务 | 覆盖与作用 | 免费边界与采用方式 |
|---:|---|---|---|
| 1 | 通达信协议 + `tdxrs` | A股指数、ETF、个股实时快照，按交易日分时，原生1/5/15/30/60分钟和前复权日线 | 图表行情唯一在线采集源；公开节点无 SLA，所有响应落盘并保留覆盖缺口。 |
| 2 | 通达信客户端本地文件 | 候选的日线和分钟历史补充 | 设置 `ARGUS_TDX_HOME`；当前只做就绪探测，解析器接入前不参与图表。目录为空时只报告未就绪。 |
| 3 | 本地 SQLite 快照 | 所有成功取得的通达信快照、分钟线和日线 | 页面始终从本地读取；断网仍可用，但必须显示最后数据时间。 |
| 4 | AKFamily / AKShare | 财务、基金、宏观等非图表补充 | 不参与上述K线周期的在线采集。 |
| 停用 | 腾讯、东方财富、BaoStock | 旧行情与抓取审计 | 通达信模式不再在线调用，历史记录不删除。 |
| 可选 | QMT/miniQMT、Futu OpenD | 券商桌面或本地网关行情 | 不再作为系统可用性的前提；只有用户已经获得免费权限时才接入。 |

当前无须安装券商软件即可启动分钟与准实时行情。推荐安装的 Windows 软件只有一个：

1. 通达信免费客户端：安装后执行“盘后数据下载”可形成后续本地补充候选。当前图表实际通过 `tdxrs` 协议节点采集；本地文件解析器接入前不会声称已读取 `vipdoc`。
QMT 和 Futu OpenD 均为未来可选扩展。没有明确免费权限时，不为数据接口开户、转入资金或改变现有持仓。

## 当前实时/分钟运行方式

```powershell
# 单次刷新默认观察列表：上证指数、两只持仓 ETF、贵州茅台测试个股
.\.venv\Scripts\python.exe -m app.data_sources.market

# 刷新任意 A 股个股；指数需要显式交易所后缀以避免与股票代码冲突
.\.venv\Scripts\python.exe -m app.data_sources.market --symbol 600519 --symbol 000001.SH

# 独立持续刷新（Web 服务启动时默认也会在后台刷新）
.\.venv\Scripts\python.exe -m app.data_sources.market --watch --poll-seconds 60
```

通达信按交易日分时接口返回分钟末价和成交量；系统把手数统一换算为股数，并将 `bar_kind` 标记为 `LAST_PRICE_POINT`，不冒充完整 OHLC。5/15/30/60分钟使用通达信原生 OHLC，120分钟由60分钟按交易时段聚合。Web 页面从 SQLite 读取，不直接等待外部节点。

## 财报、公告和基金材料

- A 股：上海证券交易所、深圳证券交易所、北京证券交易所、巨潮资讯（法定披露文件）；基金管理人官网作为第二官方来源。
- 港股：HKEXnews；公司投资者关系页面交叉核验。
- 美股：SEC EDGAR submissions/companyfacts/XBRL；公司 IR 页面交叉核验。
- 原文 PDF/HTML、公告时间、抓取时间、URL、文件哈希全部本地保存。只解析官方原文，不依赖媒体二手摘要作为“事实”。

## 宏观与 vintage

- 美国：Federal Reserve/FRED；需要历史版本时用 ALFRED vintage。FRED API key 可免费申请，不购买数据。
- 中国：国家统计局、人民银行、财政部、海关总署等官网；保存每次发布和修订快照。
- 日本/欧洲：日本银行、日本财务省、ECB、Eurostat 官方发布。
- 宏观表必须包含 `observation_date`、`release_date`、`vintage_date`、`captured_at`，回测只能看到当时已发布的 vintage，防止未来数据泄漏。

## 新闻与社交情绪

- 新闻首选官方 RSS、监管/交易所/公司公告；GDELT 可作为免费索引和发现层，但重要事件必须回到原始来源核验。
- RSSHub 可自托管为采集管道，但它不是事实来源；数据库仍引用原发布者 URL。
- X、微博、B 站、小红书、微信公众号目前没有可保证长期稳定、全量、免费的通用官方 API。首版采用 KOL 白名单、人工保存链接、允许的 RSS/公开页面和定时搜索；不绕过登录、验证码、反爬或付费墙。
- 社交节点一律先标“观点”，除非其陈述被官方材料独立证实；删除/改帖要保留抓取快照和哈希。

## 不采用

Wind、Choice、同花顺 iFinD、商业版聚宽/米筐、付费 Tushare 套餐和付费新闻流不在预算内。`yfinance`、网页逆向接口等可做海外临时补漏，但因非官方、易变化，只能作为低优先级发现源。

## 验收标准

任何数据源启用前必须通过：三年覆盖率、重复键、交易日完整性、OHLC 合法性、复权口径、单位/时区、与独立源抽样偏差、限频恢复、断网回退、原始快照重放。失败时页面展示降级，不静默切换口径。
