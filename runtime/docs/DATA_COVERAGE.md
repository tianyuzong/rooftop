## 硬性目标

- 图表在线采集统一使用通达信协议。除“五日”视图固定只显示最近 5 个交易日外，底层 1/5/15/30/60 分钟、日线及所有派生周期目标覆盖至少近 3 年；120 分钟由 60 分钟按交易时段聚合。
- 任何已成功取得的外部行情都同时保存原始响应、规范化数据库记录和 `ingestion_runs` 审计记录。
- 不用插值、复制前值或模型生成补齐缺失 K 线。
- 图表接口只读取 `data_lake/db/market_intelligence.db`，不会在页面请求时临时访问外部行情网站。

## 为什么分钟历史目前还不是3年

- 通达信按交易日分时接口可稳定取得最近5个交易日；公开节点的原生1分钟分页实测不具备可靠三年深度，因此不会把重复或不完整记录写成三年历史。
- 当前通达信公开节点的原生5/15/30/60分钟实际约2年。
- 若 `ARGUS_TDX_HOME\vipdoc` 的日线和分钟下载目录为空，需先在通达信执行盘后数据下载，再评估本地文件能否补足公开节点缺口。

因此当前状态是“1分钟可靠5日、其余原生分钟约2年、日线超过3年”，不能把分钟周期标记为三年完成。后续通达信数据按主键增量补齐，已有数据不会丢失。

## 页面可见性

图表 API 的 `coverage` 字段返回：实际首尾时间、行数、交易日数、底层周期、来源、三年要求起点及是否达标。页面标题会明确显示“已达 3 年”或“未达 3 年”，不再把数据缺口藏在图形密度里。
