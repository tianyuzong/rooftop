## 四、采集合规与数据质量硬规则

1. 优先级固定为：官方 API/RSS/下载文件 -> 获准开放平台 -> 公开网页低频采集 -> 人工 URL；不得绕过付费墙、验证码、访问控制或账号权限。
2. 仅处理公开信息；不采集私信、通讯录、非公开群聊、个人联系方式等无关个人信息。
3. 登录型采集必须单独授权；不在数据库、日志、Git 或本表中保存明文密码和 Cookie。
4. 每次查询保存原始响应、规范化正文版本、来源 URL、发布时间、观测时间、抓取时间、哈希和成功/失败审计。
5. 聚合平台只能用于“发现”；影响投资结论的事实必须回到交易所、监管机构、公司公告或原始采访独立核验。
6. 页面结构、许可条款或 robots 规则变化时自动停用适配器，保留最后可信数据并提示人工复核。
